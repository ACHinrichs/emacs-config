#+title: Emacs configuration entry point

This repository uses a literate configuration.  The executable settings live
in [[file:config/README.org][config/README.org]] and its modular notebooks; this
file is retained so that older links keep working.

Emacs starts [[file:init.el][init.el]], which is intentionally only a bootstrap:
it initializes packages and loads the modules in their documented order.  Do
not add preferences here.  Add each setting to the module that owns the
feature, with a short explanation of its purpose and any external dependency.
