#+title: Packages and Custom settings
#+PROPERTY: header-args:emacs-lisp :tangle yes

* Package sources

These archives are consulted by the bootstrap when a package is installed.
Package installation is intentionally performed by =use-package= declarations
in the feature modules, rather than by a startup-wide install sweep.

#+begin_src emacs-lisp
;;; -*- lexical-binding: t; -*-
(add-to-list 'package-archives '("gnu" . "https://elpa.gnu.org/packages/"))
(add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/") t)
(add-to-list 'package-archives '("melpa-stable" . "https://stable.melpa.org/packages/") t)
(setq use-package-always-ensure t)
#+end_src

* Custom-managed settings

second =custom-set-variables= form elsewhere in the configuration.
